# MediumRP Wiki Pages

Официальный открытый репозиторий со статьями базы знаний **MediumRP** (Minecraft DarkRP).

## Структура

- `manifest.json` — конфигурация категорий, названий и порядка отображения статей на сайте Wiki.
- `basics/` — статьи для новичков и основы сервера.
- `jobs/` — описание профессий и регламентов.
- `economy/` — экономические гайды и инструкции.
- `rules/` — правила сервера.

## Как добавить статью

1. Создайте `.mdx` файл в соответствующей папке.
2. Добавьте запись об этой статье в `manifest.json` в нужную категорию.
3. Изменения автоматически подгрузятся на сайте `mediumrp.ru/wiki` в течение 5 минут.
